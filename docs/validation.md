## 场景检查范围

以下是文本层的规则核对，不计为真实比赛、桌面操作或 Word/PDF 验收：

| 场景 | 核对结果 |
| --- | --- |
| 用户只要求润色已有材料 | 从现有文案继续，不重新开发作品；保留原话与事实范围。 |
| 没有耗时测量，却写显著提高效率 | 写作规则要求改为可见的状态变化，不能补百分比或统计显著性。 |
| 只有末页截图，没有关键步骤 | 检查已有记录；可补录则真实执行并注明，不能用示意图冒充。 |
| 截图含私密账号 | 优先重新采集公开演示数据；脱敏副本须说明性质，不能称原样。 |
| 只有文字能力，没有截图或渲染工具 | 继续独立文案工作，保留截图或视觉验收缺口，不宣称全部完成。 |
| 用户已给完整方案并要求直接执行 | 承接现授权，默认讨论和样图流程不覆盖本次明确安排。 |
